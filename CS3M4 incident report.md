The DNS replies with the correct IP address.  The browser initiates an HTTP request: It requests the yummyrecipesforme.com webpage using the IP address sent by the DNS server. The browser initiates the download of the malware. The browser initiates a DNS request for greatrecipesforme.com. The DNS server responds with the IP address for greatrecipesforme.com. As a result, The traffic is linked from the source computer to the DNS server using prot .52444(your machine.52444\<dns.google.domain) to make another DNS resolution request. the DNS server routes the traffic to a new IP address (192.0.2.172) and its associated URL (greatrecipesforme.com.http). The traffic changes to a route between the source computer and the spoofed website (outgoing traffic: IP your.machine.56378 \> greatrecipesforme.com.http and incoming traffic:greatrecipesforme.com.http \> IP your.machine.56378).   |

| Section 3: Recommend one remediation for brute force attacks |
| :---- |
| AS a cybersecurity team, we recommend some of the common security methods used to prevent brute force attacks.  Requiring a strong Password (using \!@$%, and more than 12 letters) Enforcing two-factor authentication (2FA) by text or email Monitoring login attempts Requiring more frequent password changes quarterly change passwords Disallowing previous passwords from being used Limiting the number of login attempts |
